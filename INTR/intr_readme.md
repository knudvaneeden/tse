## Description

INTR32 is a Windows-native replacement demonstration for the legacy `INTR.BIN` package. It removes the 16-bit binary module, segmented pointers, Disk Transfer Area, and DOS interrupt calls.

The original visible functions are represented as follows:

- **F1:** Enumerates `*.*` in the current directory through the Win32 `FindFirstFileA` and `FindNextFileA` APIs, then adds each name to the current TSE buffer.
- **F2:** Attempts to make the Windows console text cursor full-size and visible.

Windows 11 does not provide a direct equivalent of DOS mouse interrupt `33h` for replacing a text-mode mouse cursor with the `%` character. F2 therefore demonstrates the closest safe console-cursor operation. A graphical TSE window may have no console handle; in that case the macro reports that no console cursor is available.

## Compile the SAL macro

Keep `intr32.s`, `intr32.inc`, and the newly built `intr32.dll` together. Compile with:

```text
sc32 intr32.s
```

This should create `intr32.mac`.

## Run and test

1. Keep `intr32.mac` and `intr32.dll` in the same directory.
2. Restart TSE before testing a newly rebuilt DLL because TSE can retain DLLs in memory.
3. Load or execute `intr32.mac`.
4. Open an editable buffer and press **F1**.
5. Confirm that filenames from TSE's current working directory are added to the buffer, one per line. Long Windows filenames are supported up to the SAL string limit of 255 characters.
6. Press **F2**.
7. In a console-hosted TSE session, confirm that the text insertion cursor becomes full-height. In a graphical TSE session, the expected result may instead be the explanatory warning.

## Portability

The package does not use `LoadDir()` and contains no fixed TSE installation path. Keep the macro, include file, and DLL together. The DLL name in `intr32.inc` is simply `intr32.dll`.

The path shown above is only an example location for running the Borland compiler; it is not embedded in the source or runtime macro.

## DLL interface

The DLL exports Pascal-compatible entry points with undecorated public names:

- `IntrFindFirst`
- `IntrFindNext`
- `IntrGetNameLength`
- `IntrGetNameChar`
- `IntrCloseFind`
- `IntrSetConsoleCursor`

Filename characters are retrieved as integers and assembled by SAL. This avoids asking the DLL to modify a SAL string parameter.

## Troubleshooting

### Undefined DLL procedure or DLL load error

Verify that `intr32.dll` is beside `intr32.mac`. Restart TSE after replacing the DLL. If the error persists, use Borland `tdump -ee intr32.dll` and confirm that the six undecorated names listed above are exported.

### Linker reports an unresolved export

Run `tdump intr32.obj` and inspect the Pascal symbol spelling produced by the installed compiler. Borland normally emits uppercase symbols for `__pascal`, as mapped in `intr32.def`.

### F1 lists a different directory than expected

The `*.*` search uses the process current directory. Change to the wanted directory before pressing F1.

### F2 reports no console cursor

This is expected when TSE is running as a graphical Windows program without a standard console screen buffer. It is not a DLL-load failure.
