File: Operation: Upload: List: GoogleGroups: How to

Steps: Overview:

 1. -Goto the Google group

     1. -E.g.

          http://groups-beta.google.com/group/semware

 2. -Click on link 'Sign in'

 3. -Login using your usual Google account details
     (e.g. your Gmail account settings)

 4. -Click on link 'Files'

 5. -Click on link 'Upload new file'

 6. -Click button 'Browse' to navigate to the file you want to upload

 7. -The file is uploaded

 8. -To check, you should see that file appear in the list of already
     uploaded files
