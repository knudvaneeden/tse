# MULTIREGEX 1.0.0.0.28 — TSE SAL

Built from 1.0.0.0.27. The multiline search engine, ring-buffer enumeration, source editing, temporary-buffer cleanup, timer/profiling, and `ShowSourceDuringSearch` setting remain unchanged.

## Changes

1. **Return shortcut:** `<CtrlAlt G>` replaces `<CtrlAltShift G>` in the interactive results viewer, including after visiting a source file. This is easier to use on native Linux TSE, where Shift may not be recognized in the combination.
2. **Enter opens a result:** Pressing `<Enter>` on a match in the results viewer now visits that match's original editable buffer, just as left-click does. A header or summary row is not a valid result.
3. **Actual matched-text preview:** Instead of displaying the search expression after the source coordinates, the results list shows the first **72 characters of the actual text returned by `GetFoundText()`** after `LFind()`. Control characters and line breaks are represented by spaces; `...` means the preview was truncated. The preview is not the search expression and is not guaranteed to contain the entire match. The authoritative source buffer ID/line/column mapping is unchanged. The TSE SAL string limit of 255 characters still applies.

Example (illustrative, not generated by a run):

```
G:\WORDPROC\TSE\tse_beta44041\compile.dat(807,2): .si SemWare Macro compiler ...
```

The preview is calculated only when `LFind()` returns a match in a viewing search; it adds some text work per found occurrence, so measure runtime when comparing searches with many hits.

## Existing controls

- `agivx`: regex search across loaded normal TSE ring buffers with results view.
- `givx`: regex search current file and show matches.
- `gilvx`: regex search marked region and show matches.
- `<Enter>` or left-click: open result for normal editing.
- `<CtrlAlt G>`: return to the same result from the source.
- `<Escape>`: exit interactive results; cleanup temporary buffers and restore normal TSE keys.
- `<Ctrl L>`: repeat a non-view multiline search forward while its temporary repeat binding is active.

## Existing defaults

`ShowSourceDuringSearch=0` buffers display during scanning, and `AdaptiveWindow=30000` handles most long source lines. Extremely long physical lines can still be skipped; the final summary reports their count. The search is not guaranteed exhaustive across all possible patterns/chunk boundaries.

## Verification checklist (TSE 4.50.33)

1. Compile `sc32 multiregex.s`. This version has not been tested with that compiler in this environment.
2. On one known small `.dat` file, run expression `\.si.*\^File:` with `givx`; confirm a preview of source text appears instead of the expression.
3. Press Enter on a match, confirm it opens the correct source and allows editing, then return with `<CtrlAlt G>`.
4. Repeat for a left-click result, a header click (must not navigate), and `agivx` across two buffers.
5. Escape and verify usual `<Shift Tab>` shortcuts, normal display, and ability to purge MULTIREGEX.
6. Check performance against version 27 before using on very large files.
