# PCTAGS for The SemWare Editor

**Package version:** 1.0.0.0.1  
**Created:** 2026-09-26 14:23:07 CEST  
**Original macro:** Ron Hockemeier, version 0.10  
**Package update:** OpenAI Codex

## Description

PCTAGS searches an index generated by PC-TAGS for a function name, opens the corresponding source file, and moves to its definition. It supports a word under the cursor or a prompted name. Searches in the supplied macro are case insensitive. The macro uses a single tag file.

## Package contents

- `pctags.s` — SAL source and key assignments.
- `pctags.ini` — tag file and startup message settings.
- `pctags_readme.md` — this guide.

## Setup

1. Generate a PC-TAGS format tag file for your source code. The macro expects PC-TAGS entries containing a function name, source filename, and a `^` followed by identifying source text. A different tags format may not work.
2. Put `pctags.s` and `pctags.ini` together in the directory from which you start TSE. Put the tag file there too, or set its path in `pctags.ini`.
3. In a Windows command prompt, compile with `sc32 pctags.s`. Use the SAL compiler matching your TSE installation.
4. Load the resulting `pctags.mac` in TSE with your usual macro loading command. Keep `pctags.ini` in TSE's current directory when you run the macro.

## How to run

- Press **Alt+A** on a function name to search for that word.
- Press **Alt+P** to enter a function name in a prompt.
- Running `pctags.mac` directly runs the cursor search. It first shows an informative `Warn()` box unless `silent=true`.

When a matching entry exists, the macro opens the referenced source file and looks first for the stored phrase, then for a prefix and suffix separated by a space. It centers the match. If the tag, target file, or phrase cannot be found, TSE shows a message.

## Configuration (`pctags.ini`)

```ini
[PCTAGS]
silent=false
tagfile=pctags.tag
```

`silent=false` shows the `Warn()` box when the macro is run directly. Set `silent=true` to suppress that box; the search still runs. Other values behave like `false`. `tagfile` names the PC-TAGS index; a relative name is resolved in TSE's current directory. If the INI file or `tagfile` is absent, the macro uses `pctags.tag`.

## Notes

- The original macro supports one PC-TAGS index and searches case insensitively.
- **Alt+A** and **Alt+P** are assigned while the macro is loaded. Change the key definitions in the source and recompile if they conflict with your bindings.
- The original source says that when copying its procedures into `TSE.S`, duplicate `GetWordAtCursor()` and `GetTextUntil()` definitions must be removed.
- Compile and test in your own TSE installation; a TSE SAL compiler is unavailable in this environment.
