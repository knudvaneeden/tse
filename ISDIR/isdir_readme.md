## Description

ISDIR determines whether a supplied path names an existing directory. This package replaces RW Klein's original 1994 DOS `isdir.bin` routine with a 32-bit Windows DLL suitable for TSE Pro 4.50 on Windows 11.

The original binary used DOS interrupt `21h`, function `4300h`, and temporarily added a zero byte to TSE's string storage. The replacement copies the TSE string into a local buffer and calls the Win32 `GetFileAttributesA` function. It does not alter the string supplied by TSE.

The compatible interface is:

```text
IsDir(directory-name)
```

It returns:

- `1` when the path exists and is a directory;
- `0` when the path is a file, does not exist, is inaccessible, or is empty.

## Build the DLL

Place the package files in the Borland `BCC55\Bin` directory, or adjust the fallback `BCCROOT` setting in `build.bat`. Then run:

```text
build.bat
```

When `bcc32.exe` is beside `build.bat`, the script automatically obtains the compiler root from that location. Otherwise it uses:

```text
C:\Borland\BCC55
```

The expected messages are:

```text
Built isdir.dll successfully.
Built isdir.mac successfully.
```

The script can also receive the directory containing `isdir.s`:

```text
build.bat C:\Users\knud_\Downloads\isdir_dll
```

It then copies `isdir.dll` into that directory and compiles `isdir.s` there.

## Compile manually

The commands used by `build.bat` are:

```text
bcc32 -c -O2 -w- -tWD -I"C:\Borland\BCC55\Include" isdir.c
ilink32 -Tpd -aa -x -L"C:\Borland\BCC55\Lib" c0d32.obj isdir.obj,isdir.dll,,import32.lib cw32.lib,isdir.def
sc32 isdir.s
```

If your Borland installation is elsewhere, substitute its actual path.

## Install and run the test macro

1. Keep `isdir.dll`, `isdir.inc`, and `isdir.s` together.
2. Run `sc32 isdir.s` to create `isdir.mac`.
3. Keep `isdir.dll` beside `isdir.mac` in the TSE macro directory.
4. Start TSE Pro.
5. Execute the macro `isdir`.
6. Enter a path at the `Directory name:` prompt.
7. The final warning reports whether the path is an existing directory.

Example test values:

```text
C:\Windows
C:\Windows\notepad.exe
C:\directory_that_does_not_exist
.
..
```

`C:\Windows`, `.` and `..` should be reported as directories. The executable and nonexistent path should not.

## Use the DLL from another SAL macro

Put `isdir.inc` beside the calling source and add:

```text
#include ["isdir.inc"]
```

Then call the function, for example:

```text
string fileNameS[255] = "C:\\Windows"

if IsDir(fileNameS)
    Warn("This is a directory.")
else
    Warn("This is not a directory.")
endif
```

Keep `isdir.dll` in the same macro directory as the compiled macro. No editor installation directory or `LoadDir()` dependency is used.

## Troubleshooting

### Undefined symbol ISDIR

Confirm that `isdir.dll` was built with `isdir.def` and that the DLL is beside the compiled TSE macro. Do not use the old `binary` declaration with the DLL version.

### DLL cannot be loaded

Confirm that TSE Pro is 32-bit and that `isdir.dll` is also 32-bit. A 64-bit DLL cannot be loaded into 32-bit TSE.

### Rebuilt DLL appears unchanged

TSE can keep a loaded DLL in memory. Exit and restart TSE after replacing `isdir.dll`.

### A directory returns zero

Check that the path exists and that the current Windows account can access it. Try a fully qualified path. TSE strings are limited to 255 characters, so this interface does not support longer paths.

## Compatibility notes

- The exported function keeps the original name `IsDir` and Boolean integer result.
- The DLL uses the Win32/Pascal-compatible `WINAPI` calling convention expected by TSE's DLL interface.
- The supplied path is copied and zero-terminated safely inside the DLL.
- The implementation is ANSI because TSE SAL uses 8-bit strings rather than UTF-8 or UTF-16 strings.
- The old `isdir.bin` remains in `original` for historical reference only and is not needed by the DLL version.
