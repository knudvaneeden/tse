#                         General Information                             |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

This software is provided "as is" without express or implied warranty.

All macro settings are stored in the TSE.ini file. The used sections are
[FppShell], [FppSum] and [FppSumLine].

Fpp*.mac are a shell for the 'F'loating 'P'oint 'P'arser 'Con'sole
version FppCon_*.exe where all the calculation is done. These macros
call FppCon_*.exe with the needed number of arguments.

FppCon_*.exe is a simple line-parser consisting of a compiler-
interpreter- system. There are no control-structures and no conditionals.
The compiler generates stack based p-code and doesn't do any optimizations.

All integer values are 64 bit wide.

All bitmanipulating functions as well as conversions treat integers
as signed integers. If they exceed the integer limit of 64 bit in such
a function you will get an errormessage.

+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+
#   Parameter separators within functions with more than one parameter    |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

The parameter separator used in functions can be either a "," or a "|".

Note :
======
Due to the special handling of decimal and grouping separators when
building sums the "|" *must* be used as a parameter separator in your
expression if you want to use functions with more than one parameter in
combination with FppSum or FppSumLine.

Example: Max(190,3) or Max(190|3) in combination with FppSum or FppSumLine
         "ff,16"    or "ff|16"    in combination with FppSum or FppSumLine

A t t e n t i o n :
===================
When building sums (FppSum, FppSumLine)
- Each generated result within an expression line will be used for sum.
- Assignments (like A=...) are not part of the sum!


+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+
#                         Precedence of operators                         |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

()     Sub expression                           (highest)

(-)    Negation

^      Exponentiation

*, /   Multiplication and division

+, -   Addition and subtraction                 (lowest)

When multiplication and division occur together in an expression,
each operation is evaluated as it occurs from left to right.
Likewise, when addition and subtraction occur together in an expression,
each operation is evaluated in order of appearance from left to right.


+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+
#                    Expression separators and remarks                    |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

An expression is not case sensitive.
Example: a = 10 * (b + c) is identical to A = 10 * (B + C)

An expression-line can consist of several expressions. In this case
each expression must be separated by a ':' or ';'.

Example: a=10 : b=20 ; c=a+b
   Remember, only the last result (c=a+b) [30] is displayed (FppShell).

There are some build in constants. They can be used like a variable
except you can't assign them a value.

Example: a=2*pi    will assign the result 2*pi (6.28...) to variable a.
        pi=2*pi    will give an errormessage

Remarks can be inserted in an expression by using '//'

Example: a=10:b=20:c=a+b  // addition of 2 vars

         1+2+3+4+5//+6+7+8
         The evaluation stops at the first occurrence of the '//'.
         In this case only 1+2+3+4+5 is evaluated.

Large numbers can also be entered by grouping them with one or more spaces.
This way they may be easier to type and read.

  Examples of valid inputs for different bases:
  Decimal number (base 10)
  1234567890.1234
  1 234 567 890.1234

  Hex number (base 16)
  $1122334455667788
  $1122 3344 5566 7788

  Binary number (base 2)
  %1111000000001111111100000000111111111111111111111000000001000001
  %11110000 00001111 11110000 00001111 11111111 11111111 10000000 01000001


--------------
FppShell only:
--------------
  The expression-line accepts numbers in US format without any other separators
  than space only.

  Example of valid inputs:
  1234.567
  1 234.567

  1,234.567 will not be accepted and give an error

---------------------------
FppSum and FppSumLine only:
---------------------------
  Fully localized numbers are supported.

  Example of valid inputs (US-Standard localization):
  1234.567
  1 234.567

  1,234.567 is also a valid input


+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+
#       Entering values in binary formats (sample value 255 base 10)      |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

-----------------------------
Entering hex (base 16) values
-----------------------------
  Prefix "0x...", "$...", "&..." or "&h..."

  Examples:
  0xFF or $FF or &FF or &hFF

------------------------------
Entering octal (base 8) values
------------------------------
  Prefix "&o..." or "&q..."

  Examples:
  &o377 or &q377

-------------------------------
Entering binary (base 2) values
-------------------------------
  Prefix "%..." or "&x..."

  Examples:
  %11111111 or &x11111111

------------------------------------------
Entering values from other bases (2 to 36)
------------------------------------------
  Syntax: "<constant value>,<constant base of value>"

  The double/single quotes "..." or '...' must be entered.
  The <constant base value> is always expected to be a decimal value.

  Examples:
  "FF,16" or "11111111,2" or "100110,3"
  'FF,16' or '11111111,2' or '100110,3' when used from command line eval-mode
  "FF|16" or "11111111|2" or "100110|3" in combination with FppSum or FppSumLine

--------------------------------
Entering single float hex values
--------------------------------
  Prefix "!..."

  Float 32 (single float) Format:
 +---------------------------------------+
 |  byte 1 |  byte 2 |  byte 3 |  byte 4 |
 +---------+---------+---------+---------|
 |SEEE EEEE|EMMM MMMM|MMMM MMMM|MMMM MMMM|
 +---------------------------------------+
  S = Sign bit      (bit 31)
  E = Exponent bits (bits 30 - 23)
  M = Mantissa bits (bits 22 - 0)

  The display of the number in the main-window is arranged in the
  above order. The input is also expected in that order.

  Example:
  !437F0000

--------------------------------
Entering double float hex values
--------------------------------
  Prefix "#..."

  Float 64 (double float) Format:
 +-----------------------------------------------------+
 |  byte 1 |  byte 2 |  byte 3 |  byte 4 |...|  byte 8 |
 +---------+---------+---------+---------+---+---------|
 |SEEE EEEE|EEEE MMMM|MMMM MMMM|MMMM MMMM|...|MMMM MMMM|
 +-----------------------------------------------------+
  S = Sign bit      (bit 63)
  E = Exponent bits (bits 62 - 52)
  M = Mantissa bits (bits 52 - 0)

  The display of the number in the main-window is arranged in the
  above order. The input is also expected in that order.

  Example:
  #406FE00000000000


+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+
#                               Variables                                 |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

Up to 100 variables can be stored. Variables are declared and
initialized automatically when they are first used. Variable names must
start with a letter (a-z) or with an underscore (_). The name may consist
of letters, underscore and numbers up to 32 characters long.

Example: '_1ST_VAR' or 'A_VAR' are valid names
         '1_TEST' is an invalid name

The Variable 'RES' is a fixed name. RES represents the value of the last
evaluation and can be included in an expression.

Example: a=1+1:res+7  // the displayed result will be 9

FppShell.mac is a shell for the 'F'loating 'P'oint 'P'arser 'Con'sole

The number of digits can be set in the Options menu.

When grouping is active, the values are formatted with the local symbols
for decimal and thousand separators (US=1,234.5 Non-US=1.234,5 and so on).

If the macro is started the first time you won't see any value displayed.
As long as the value fits in 64 bit integer range the integer part of
the value is displayed in the upper 5 lines. One 'x' in the 'Values' line
stands for 8 bit. Coloring of the values in the upper 3 lines will only be
applied when the base is set to 2 or 16.

If a value is too big to be represented the specific area will be displayed
filled with '-' instead.

The top three lines are predefined with the bases 2, 8 and 16. Each line
can be separately set to a base from 2 to 36. The settings are saved in
the TSE.ini file. These lines only display the unsigned integer (positive value)
part of the result.

IEEE displays the result as hex, decimal and as the binary representation.
The Bin lines color the sign bit, the exponent bits and the mantissa bits.

The Result is normally displayed in the same line as the word Result. In
case it is to long for that line a second line is used. If it still is to
big to be displayed the second line is truncated and a right arrow is
placed at the last position. Truncation is only used for displaying the
value, not for inserting it in text.

The two lines below the expression are reserved for error-messages from
the parsing routines. The first line will show compiler/interpreter
messages, the second will show math errors if they occur.

In case of an error the cursor is positioned as close as possible to
where it was detected within the expression string.

The Expression-line is 255 character long, so it will scroll when reaching
the right boundary of the window.

The Variable 'TSUM' is a fixed name. TSUM represents the current total sum and
is intended to make it easier to calculate taxes or discounts at the end of the
list. TSUM is protected and can't be manipulated, it can only be queried.

Note :
======
The TSUM variable is available in FppSum and FppSumLine only!

Localization used in all these examples is US-Standard.


>Example showing the content of a variable without adding it to the sum:

correct sum. So it is displayed twice. The first (Salad) displays the content
and is added to the sum. The second (-Salad) is also displayed but subtracted
from the sum. This way it's a cancellation of an entry.

This might be helpful while developing and testing your own formular and should
be removed when testing is done.

some cases due to the special handling when building sums.

#                 About the TOC (T)able (O)f (C)ontents                   |
+=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=+

You can add your own comments or examples anywhere in this file by editing it.
If you want them to have an entry shown in the TOC for easy access, simply
put a *number sign* "#" as the *first* character at the start of the line before
any of your text. This way the entry will automatically be displayed in the TOC.
For an example see the already showing entries.

The "#" is the default setting which is used in this file to mark the lines to
display in the TOC. This setting can be changed and set individually for each
macro to use a customized TOC.

If you want you can use your own TOC-marker sign. You are not limited to the
default, simply replace/change/add/remove them to your liking with your own
marker-sign by editing this file.

A TOC-marker sign can consist of max 5 characters.

It's also possible to use different markers in the help and by switching the
marker to display a different TOC. If you want to try it out, there are some
lines marked using a ">" as alternative marker. Simply change the marker in the
macro from "#" to ">" and open the TOC list. It now only shows the lines marked
with ">". This is only to give an example of what could be done.

To change it:
FppShell   by using the Options-menu (L - TOC-Marker Sign)
FppSum     by using menu option (E - TOC-Marker Sign)
FppSumLine by using menu option (H - TOC-Marker Sign)

The color of the marker can be changed for use with all Fpp* macros by using the
FppShell Options-menu (A - Set Colors... -> L - TOC-Marker Color...).

Note :
======
If the help-file is updated with a newer version, unfortunately you have to
merge your adds and changes with the updated file.

Abs(a)
------
  Returns the absolute value of its argument.

  Example:
  Abs(-4)   = 4
  Abs(-pi)  = pi (3.14...)

-------
Acos(a)
-------
  Returns the inverse cosine of a in the range 0 to pi radians.
  a must be a value between -1 and 1.

  Example:
  Acos(0.0) = 1.570796...

--------
AcosH(a)
--------
  Returns the inverse hyperbolic cosine of a. a must be a value >= 1.

  Example:
  AcosH(pi) = 1.811526...

And(a,b)  [And(a|b) -> in combination with FppSum or FppSumLine macro]
--------
  Returns the integer binary value of a anded with integer value of b.

  Example:
  And($FF, $0F) = $0F

----------
Angle(a,b)  [Angle(a|b) -> in combination with FppSum or FppSumLine macro]
----------
  Returns the quadrant correct inverse circular tangent in radians.

                      y-axis
                      pi/2
                        |
             quadrant 2 | quadrant 1
                        |
        (pi/2) < o < pi | 0 < o < (pi/2)
                        |
                        |   o <-\  o-direction
                        |        \
     pi ----------------+--------------- 0 x-axis
                        |
                        |
      -pi < o < -(pi/2) | -(pi/2) < o < 0
                        |
             quadrant 3 | quadrant 4
                        |
                     -(pi/2)
  Example:
  Angle(-3, -2)     = -2.553590...    (quadrant 3)

  To get the result in degrees:
  Deg(Angle(-3,-2)) = -146.309932...  (quadrant 3)

  Shr32 only right shifts the 32 bit part of the 64 bit value a.
  Returns the 64 bit integer binary value where only the 32 bit part
  of a is shifted right b times.
  Range of b is 0 to 31.

  Example:
  Shr32($1234567840000000,28) = $1234567800000004

----------------
ShrBits(a,b,c,d) [ShrBits(a|b|c|d) -> in combination with FppSum or FppSumLine macro]
----------------
  ShrBits only right shifts the specified range of value a.
  b = Start-bit, Range 0 to 63, must be <= End-bit
  c = End-bit,   Range 0 to 63, must be >= Start-bit
  d = Steps,     Range 0 to 63

  Example:
  ShrBits(%11100000101,3,9,3) = %10001100101

------
Sin(a)
------
  Returns the sine of a in radians. a must be in radians.

  Example:
  Sin(pi/2) = 1

---------
SinDeg(a)
---------
  Returns the sine of a in radians. a must be in degrees.

  Example:
  SinDeg(90) = 1  [same as Sin(Rad(90))]

-------
SinH(a)
-------
  Returns the hyperbolic sine of a.

  Example:
  SinH(pi/2) = 2.301298...

-------
Sqrt(a)
-------
  Returns the square-root of a. a must be a positive value.

  Example:
  Sqrt(16) = 4   [same as 16^(1/2)]

-------
Swap(a)
-------
  Returns the integer binary value of the swapped a.
  Swapping is done by changing high 32 bit with low 32 bit of the 64 bit value.

  Example:
  Swap($1122334455667788) = $5566778811223344

--------
Swap8(a)
--------
  Returns the integer binary value of the swapped a.
  Swapping is done by changing high 8 bit with low 8 bit of each 16 bit part.

  Example:
  Swap8($1122334455667788) = $2211443366558877

---------
Swap16(a)
---------
  Returns the integer binary value of the swapped a.
  Swapping is done by changing high 16 bit with low 16 bit of each 32 bit part.

  Example:
  Swap16($1122334455667788) = $3344112277885566

------
Tan(a)
------
  Returns the tangent of a. a must be in radians.

  Example:
  Tan(1.5) = 14.101419...

---------
TanDeg(a)
---------
  Returns the tangent of a. a must be in degrees.

  Example:
  TanDeg(85) = 11.430052...  [same as Tan(Rad(85))]

-------
TanH(a)
-------
  Returns the hyperbolic tangent of a.

  Example:
  TanH(1) = 0.7615941...

--------
Xor(a,b)  [Xor(a|b) -> in combination with FppSum or FppSumLine macro]
--------
  Returns the binary integer value of a xored with b.

  Example:
  Xor($F0,$FF) = $0F

To display all(?) or specific(?..) help type:
FppCon_x64.exe ?[ev/pa/su/sl/fl/cl]

Currently there are 6 commands available:
Eval (ev), Parse (pa), Sum (su), SumLine (sl), Flist (fl) and Clist (cl).
Each command has its own set of parameters.

======
Usage:
======
FppCon_x64.exe Command -aParam1 -bParam2 [-cParam3] ...

==========+==============================

          +------------------------------

-b<...>   |Mnemonic -> Short description
[-c<...>] |Mnemonic -> Short description

Example:

FppCon_x64.exe cmd -aParam1Data -bParam2Data

Parameter included in brackets are [optional].

===========
Usage EVAL:
===========
FppCon_x64.exe ev[-x<Num>-y<Num>-z<Num>-d<Num>] <Expr>

==========+===========================================================================
EVAL      |[Options]  Expression
==========+===========================================================================
ev or evc |[-x-y-z-d] <Expr> (see note below)
<Expr>    |Expression typed at the command line
----------+---------------------------------------------------------------------------
[Options] |If one or more are used they **MUST** be glued to ev without any space!
          |*OR* they whole command "ev including options part" **MUST** be "quoted"!
          |Not doing so will result in an error!
----------+---------------------------------------------------------------------------
[-x<Num>] |[Base1]      -> Basenumber1 for result to convert to (2-36), Default [2]
[-y<Num>] |[Base2]      -> Basenumber2 for result to convert to (2-36), Default [8]
[-z<Num>] |[Base3]      -> Basenumber3 for result to convert to (2-36), Default [16]
[-d<Num>] |[Digits]     -> Number of digits for result display  (0-99), Default [53]

[-us] or [-nu] or [-sy] may be added to localize most of the results.
Localize uses the local decimal and thousands separators, also local grouping.
[-us] : US-Standard settings 1,234.00 (default)
[-nu] : Non-US settings 1.234,00
[-sy] : System settings

Note:
-----
evc is identical to ev, except that it uses coloring to display the result.

**Coloring may not work with every command-line tool and every Windows version**

To change the default colors see FppHelp.txt, section 'Using FppCon.ini' for
details.

Examples:
---------
FppCon_xxx.exe ev   1 + '10200, 3'
FppCon_xxx.exe evc  1 + '10200, 3'
FppCon_xxx.exe ev-us-x2-y8-z16-d98   pi / 2
FppCon_xxx.exe "ev -nu -d98"   scale = 3840 / 1920 : scale - mod(scale, 0.1)

The file 'FppCon.ini' is currently used when running FppCon_*.exe with the evc
command only. The name is fixed, also the location of the file. When used it
has to be located in exactly the same directory as the FppCon_*.exe files.

Note:
Not every command-line tool and Windows version support coloring!
It works fine running Windows 11 Pro and the Microsoft command-line.

coloring the result display. To change it to your liking mark all the lines
between Start and Stop and save the block to the file and location as mentioned.
