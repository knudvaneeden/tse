# AFTROCR for The SemWare Editor (TSE)

## Description

AFTROCR is a collection of TSE SAL macros for finding and correcting common errors in text produced by optical character recognition (OCR). The package was originally written by Carlo Hogeveen and was tested with TSE Pro 2.50e and TSE Pro/32 2.80d.

The archive `aftrocr_1.0.0.0.0.zip` contains the following main macros:

| Macro | Purpose |
|---|---|
| `FUBOOKDU.S` | Finds and deletes adjoining identical blocks of text, such as a book page that was accidentally scanned twice. |
| `OCR_BL.S` | Automatically replaces consistently misrecognized, normally nonexistent words using correction pairs stored in `OCR.LST`. It creates a report showing the replacements. |
| `2WRDLIST.S` | Finds pairs of valid words that OCR software may have confused and lets you decide interactively whether each occurrence should be exchanged. The pairs are stored in `2WRDLIST.WRD`. |
| `GOODCASE.S` | Corrects unexpected uppercase letters inside words while preserving all-uppercase words, initial capitals, and capitals following `Mac` or `Mc`. |
| `SORT.S` | Sorting macro required by `OCR_BL.S`. |

The package also contains:

- `OCR.LST` — example automatic OCR correction list.
- `2WRDLIST.WRD` — example interactive word-pair list.
- `aftrocr.ini` — local AFTROCR initialization file; it is separate from `tse.ini`.
- `aftrocr.zip` — a copy of the original historical AFTROCR distribution.
- `README.txt` and `FILE_ID.DIZ` — original documentation.

## Important precautions

The macros can modify the text in the current TSE buffer. Before processing an important OCR document:

1. Save a backup copy of the original text file.
2. Test the macros on a small copy first.
3. Carefully inspect the resulting text before saving it.
4. In particular, inspect the report generated by `OCR_BL` because every matching entry is replaced automatically.

## Installation

### 1. Extract the package

Extract `aftrocr_1.0.0.0.0.zip` into an arbitrary working directory.

The old `README.txt` refers to `zipinstallaftrocr.bat`, but that batch file is not included in this package. It is therefore unnecessary for the installation described here.

### 2. Choose the macro directory

You can either:

- copy the `.S`, `.LST`, and `.WRD` files to your normal TSE macro directory; or
- keep them together in your TSE SAL working directory.

The data files must remain accessible to the compiled macros.

### 3. Set the data-file paths

Before compiling, open `2WRDLIST.S` and change this line if your macro files are not in `C:\TSE\MAC`:

```sal
string wordfile_name[255] = "c:\tse\mac\2wrdlist.wrd"
```

Open `OCR_BL.S` and change these lines in the same way:

```sal
string ocr_filename     [255] = "c:\tse\mac\ocr.lst"
string changes_filename [255] = "c:\tse\mac\ocr.mut"
```

For example, if the package is installed in `D:\TSE\AFTROCR`, use:

```sal
string wordfile_name[255] = "d:\tse\aftrocr\2wrdlist.wrd"
```

and:

```sal
string ocr_filename     [255] = "d:\tse\aftrocr\ocr.lst"
string changes_filename [255] = "d:\tse\aftrocr\ocr.mut"
```

### 4. Compile the macros

Compile these source files with the TSE SAL compiler appropriate for your TSE installation:

```text
SORT.S
FUBOOKDU.S
OCR_BL.S
2WRDLIST.S
GOODCASE.S
```

For a 32-bit TSE installation, this can normally be done from a command prompt in the source directory with commands such as:

```bat
sc32 sort.s
sc32 fubookdu.s
sc32 ocr_bl.s
sc32 2wrdlist.s
sc32 goodcase.s
```

This should create the corresponding compiled `.MAC` files. Make sure TSE can find those files in its macro path.

## How to run the macros

1. Start TSE.
2. Open the OCR-generated text file that you want to process.
3. Make sure that this text file is the current TSE buffer.
4. Run the desired compiled macro by its macro name, for example from TSE's **Execute Macro** command.
5. Review the changes and save the document only when satisfied.

A practical processing order is:

1. `FUBOOKDU` — remove accidentally duplicated adjoining pages or blocks.
2. `OCR_BL` — apply the automatic corrections in `OCR.LST`.
3. `2WRDLIST` — examine ambiguous pairs of valid words interactively.
4. `GOODCASE` — correct unexpected capital letters, preferably as the last cleanup step.

The macros are independent, so you only need to run the ones appropriate for the document.

## Macro help

### FUBOOKDU — remove duplicated adjoining text

Run `FUBOOKDU` on the current text file. It searches for adjoining identical line blocks and deletes the duplicate block.

Large files can take considerably longer to process than small files. The original documentation reports that processing time increases sharply with file size. The macro also requires lines no longer than 254 characters.

After it finishes, inspect every area where duplicate text was removed before saving.

### OCR_BL — automatic OCR word correction

`OCR_BL` uses `OCR.LST`. Each line in that file has this format:

```text
incorrect_word|correct_word
```

The words may contain only characters recognized by TSE as word characters; spaces and other non-word characters are not allowed inside an entry. Searching is case-insensitive, and the macro tries to preserve the capitalization pattern of the original word.

Run `OCR_BL` while the OCR text is the current buffer. It automatically performs every matching replacement, then displays a newly created report buffer showing which words were replaced and how often. Use TSE's previous/next file commands—traditionally `Alt+P` and `Alt+N`—to move between the report and the text.

Review the report carefully. Edit `OCR.LST` to remove unsafe corrections and add corrections appropriate to your own OCR material.

`OCR_BL` calls the `SORT` macro internally, so `SORT.MAC` must be compiled and available to TSE.

### 2WRDLIST — interactive correction of ambiguous words

Use `2WRDLIST` when both possible OCR results are valid words and an automatic replacement would be unsafe.

Each line of `2WRDLIST.WRD` has this format:

```text
word1 word2 options
```

The options are:

| Option | Meaning |
|---|---|
| `W` | Match whole words only. |
| `A` | Always replace `word1` with `word2` automatically. |
| `AW` or `WA` | Apply both options. |
| no option | Find both words and let the user decide. |

For manual review, the macro uses the numeric keypad keys:

| Key | Action |
|---|---|
| Grey `+` | Find the next occurrence. |
| Grey `-` | Exchange the found word with the other word in the pair. |
| Grey `Enter` | Skip the remaining occurrences of the current pair and continue with the next pair. |
| Grey `/` | Display the current word pair. |

When a word is exchanged, the macro attempts to preserve lowercase, uppercase, or initial-capital form.

Although the `A` option is supported, replacements that are always safe are generally processed more efficiently by adding them to `OCR.LST` and using `OCR_BL`.

### GOODCASE — correct capitalization inside words

Run `GOODCASE` on the current text buffer. It applies these rules:

1. Words written entirely in uppercase are left unchanged.
2. The first letter of a word is left unchanged.
3. A capital letter following `Mac` or `Mc` is left unchanged.
4. Other uppercase letters occurring inside words are changed to lowercase.

Because unusual capitalization can sometimes indicate an OCR error other than case alone, run this macro last and review its changes before saving.

## Customizing the correction lists

The included `OCR.LST` and `2WRDLIST.WRD` files are examples intended to be edited.

- Add a pair to `OCR.LST` only when the first form can safely be replaced automatically in every occurrence.
- Add a pair to `2WRDLIST.WRD` when both forms are real words and the correct choice depends on context.
- Keep backups of your customized lists when installing a newer package.
- Avoid duplicate or contradictory correction entries.

## Troubleshooting

### TSE cannot find `2WRDLIST.WRD` or `OCR.LST`

Check the absolute filenames near the beginning of `2WRDLIST.S` and `OCR_BL.S`, then recompile the changed source files.

### `OCR_BL` cannot execute `SORT`

Compile `SORT.S` and place `SORT.MAC` in a directory searched by TSE for macros.

### The numeric keypad commands do not work in `2WRDLIST`

Use the physical numeric keypad keys corresponding to Grey `+`, Grey `-`, Grey `Enter`, and Grey `/`. Keyboard mappings and Num Lock behavior can differ between systems.

### A macro changes too much text

Do not save the buffer. Abandon or reload the changed file, adjust the relevant correction list, and run the macro again on a fresh copy.

### Compilation fails in a newer TSE SAL compiler

These macros were originally written for older TSE versions. Compile the included sources unchanged first, except for the required data-file paths. If errors occur, record the complete compiler output, including line and column numbers, before modifying the source.
