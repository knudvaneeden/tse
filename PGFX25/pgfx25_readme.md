# PGFX25 - Pretty Good Folding for TSE 2.5

- Documentation generated by: OpenAI Codex

## Description

PGFX25 is the TSE 2.5 adaptation of **PGF - Pretty Good Folding**. It lets you temporarily collapse paragraphs or marked line blocks to a single visible line. The removed text is retained in a separate fold-buffer file and can later be restored.

PGFX25 can:

- fold the paragraph at the cursor;
- fold a marked line block into one fold;
- fold multiple paragraphs into separate folds;
- expand the fold on the cursor line;
- expand all folds in a marked block or the current file;
- find the next folded line;
- show fold locations in loaded files;
- open the fold-buffer file for inspection;
- save the source and fold-buffer files automatically after folding or expanding.

This special version was adapted from PGF 1.054 for TSE 2.5. Features from the TSE Pro 4.4 edition that are not available in this adaptation include fold-code highlighting, fold-code protection, the reminder ribbon, and the hooks used by those features.

## Package contents

- `pgfx25.s` - TSE SAL source code.
- `pgfx25.doc` - original PGFX25 documentation.
- `pgfx25.ini` - initialization/reference settings supplied with this package.
- `pgfx25_readme.md` - this guide.

After compilation, TSE creates `pgfx25.mac`. While PGFX25 is active, it uses `pgffold.dat` in the macro load directory as its persistent fold buffer.

## Important safety information

Test the macro first on disposable or backed-up files. Folding changes the source file and stores the removed text in `pgffold.dat`.

The first three characters of a folded line are PGFX25's fold code. Do not edit or delete that code. Also do not edit the fold-code lines or fold-separator lines inside `pgffold.dat`, because PGFX25 needs them to restore the text correctly.

Keep `pgffold.dat` together with files that still contain folds. A source file containing fold codes cannot be expanded correctly if its matching fold-buffer data is lost.

## Installation and compilation

1. Extract `pgfx251.0.0.0.0.zip` into a working directory.
2. Make a backup of any files on which you intend to test folding.
3. Compile `pgfx25.s` with the TSE SAL compiler appropriate for TSE 2.5.
4. Confirm that the compiler creates `pgfx25.mac` without errors.
5. Place `pgfx25.mac` where TSE can load or execute it.
6. Keep `pgfx25.doc`, `pgfx25.ini`, and this README for reference.

The supplied `pgfx25.ini` records the intended initial settings. Revision PgfRev1054 does not read this INI file; its runtime defaults remain defined in `pgfx25.s`.

## Starting PGFX25

1. Open a text file in TSE.
2. Execute the compiled macro `pgfx25.mac`, or press `<CtrlShift P>` followed by `<P>` if that key assignment is active in your TSE setup.
3. PGFX25 displays its menu and initializes the hidden fold buffer.
4. When activation is complete, the message line reports that PgfRev1054 is active.

The source assigns the operation keys with the `<CtrlAltShift P>` prefix, while the original documentation describes a `<CtrlShift P>` prefix. Because key interpretation can depend on the TSE version and keyboard configuration, use the displayed menu if a shortcut does not respond.

## How to fold one paragraph

1. Put the cursor on any nonblank line in the paragraph.
2. Open the PGFX25 menu.
3. Choose **Fold Paragraph or Block To One Fold Line**.
4. The first text line remains visible with a three-character fold code at columns 1 through 3. The remaining text is moved to `pgffold.dat`.

A one-line paragraph cannot be folded. The top line must not already be a folded line.

## How to fold a marked block into one fold

1. Mark the required text as a line block.
2. Open the PGFX25 menu.
3. Choose **Fold Paragraph or Block To One Fold Line**.
4. PGFX25 excludes blank lines at the top and bottom of the block and folds the remaining text into one fold line.

The block may contain existing folds, but its first text line must not already contain a fold code.

## How to fold several paragraphs separately

1. Mark the paragraphs as a line block. If no line block is marked, PGFX25 processes the complete current file.
2. Open the menu.
3. Choose **Fold Paragraphs To Multiple Fold Lines**.
4. Each eligible multi-line paragraph becomes its own fold line.

Single-line paragraphs and paragraphs that are already folded are ignored.

## How to expand one fold

1. Put the cursor on the line containing the fold code.
2. Open the menu.
3. Choose **Expand Folded Text At CursorLine**.
4. PGFX25 retrieves the matching text from `pgffold.dat` and restores it in the source file.

Only the selected outer fold is expanded. Any folds contained inside it remain folded.

## How to expand multiple or all folds

1. To limit the operation, mark a line block containing the folds to restore.
2. To process the complete current file, leave no line block marked.
3. Open the menu.
4. Choose **Expand All Folded Text**.

## Other menu commands

- **Find Next Folded Text** searches forward for the next fold code. TSE's repeat-find commands can then continue forward or backward until another search replaces it.
- **Show All Fold Locations** shows fold-code matches found in loaded files.
- **View The PGF Fold Buffer** opens `pgffold.dat`. Run the same view command again to return to the original file. Do not change control or separator lines in this file.
- **Toggle AutoSave On/Off** changes automatic saving for the current PGFX25 session. AutoSave is on by default.
- **Simple Help** opens the built-in quick-help page.
- **Terminate Macro** disables PGFX25 for the current session without deleting the saved fold data.

## Assigned keys

The active declarations at the end of `pgfx25.s` are:

| Key sequence | Operation |
|---|---|
| `<CtrlAltShift P>` then `<M>` | Open the PGFX25 menu |
| `<CtrlAltShift P>` then `<F>` | Fold a paragraph or block into one fold |
| `<CtrlAltShift P>` then `<E>` | Expand the fold on the cursor line |
| `<CtrlAltShift P>` then `<->` | Fold paragraphs into multiple folds |
| `<CtrlAltShift P>` then `<=>` | Expand all applicable folds |
| `<CtrlAltShift P>` then `<G>` | Find the next fold code |
| `<CtrlAltShift P>` then `<S>` | Show all fold locations |
| `<CtrlAltShift P>` then `<V>` | View or leave the fold buffer |

The separate execution/termination assignment near the beginning of the source is `<CtrlShift P>` followed by `<P>`.

## AutoSave

AutoSave starts enabled. After a successful single fold or expansion, PGFX25 saves both the current source file and `pgffold.dat`. The multiple-fold and expand-all operations also save their changes when AutoSave is enabled.

Turning AutoSave off only affects the current running instance. Save the source file and fold buffer manually before exiting if AutoSave has been disabled.

## The initialization file

`pgfx25.ini` contains descriptive initial values for this package:

- `autosave=yes`
- `foldbuffer=pgffold.dat`

PGFX25 PgfRev1054 does not parse the INI file. These values document the built-in defaults and provide a starting point for a future INI-enabled revision. Editing the INI file alone does not change the current macro's operation.

## Ending and resuming work

1. Expand any folds that should not remain stored externally.
2. If folds will remain, ensure AutoSave is on or save both the source file and `pgffold.dat` manually.
3. Choose **Terminate Macro** or use the execution/termination key.
4. On a later TSE session, load the source file and execute `pgfx25.mac` again.
5. PGFX25 reopens `pgffold.dat`, scans its existing fold codes, and can expand the saved folds.

## Troubleshooting

### Nothing happens when a shortcut is pressed

Open the macro by executing `pgfx25.mac` and use its menu. Check for conflicts in your TSE key assignments, and note the prefix difference between the original documentation and the active declarations in the source.

### "Macro not Active or in PGF Fold Buffer. Nothing done."

Execute PGFX25 to activate it, then return to a normal source file. Folding and expansion commands are intentionally blocked while the fold-buffer file is current.

### "Cannot fold one line paragraphs."

The selected paragraph or marked block contains only one eligible text line. Select a larger line block or move to a multi-line paragraph.

### "Cannot Fold Line Already Folded."

The first selected text line already contains a fold code. Expand that fold first or begin the new block on an unfolded line.

### "No Fold Code on Cursor Line. Nothing done."

Move the cursor to the visible line whose first three characters are the PGFX25 fold code, then run the expand command again.

### A saved fold cannot be expanded

Verify that the original matching `pgffold.dat` is still present in the macro load directory and has not been edited. Also verify that the three-character fold code at the start of the source line has not been changed or deleted.
